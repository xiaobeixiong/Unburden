# Redundant Logic and Rules: irrelevant negative contrasts

The opening of a single-purpose image-compression utility introduces unrelated product categories only to reject them: "not an image editor, not an asset manager, and not a creative suite, but ...". The positive clause already explains the utility's function. Each snapshot includes its own page purpose, accepted inputs, requested size limit, and output definition.

| Path | Role |
| --- | --- |
| [base/article.md](base/article.md) | Direct description of the compression utility. |
| [candidate/article.md](candidate/article.md) | Adds three product-category exclusions to the introduction. |
| [findings.md](findings.md) | Expected comparison and snapshot reports. |
| [improved.md](improved.md) | Removes the negative preamble while retaining the capability and output. |
| [non_finding.md](non_finding.md) | Retains a meaningful contrast specifying local processing instead of server upload. |

Use only `base/` and `candidate/` as the repository endpoints, or only `candidate/` for snapshot review. This README, expected findings, and alternatives are explanatory material outside the inputs. The sources are fictional prose illustrations, not a tool to execute.

This is distinct from the [repeated-qualification example](../writing/README.md): the rejected alternatives appear only once. The evidence is the stated purpose of this opening and the contribution of each clause, not a keyword match, a word-count target, or an assumed prior conversation. The removed clauses add product-category comparisons outside the opening's stated purpose; the retained clause and following sentence supply all specified input, size-limit, and output information. The suggestion makes no broader claim about the product's capabilities.

In the non-finding, the negative clause defines the data-processing boundary requested by that page's purpose. Removing it would lose information. Likewise preserve negatives that correct an established misconception, explain a real method comparison, or convey a necessary limitation. If the role of a contrast is unclear, omit the finding.
